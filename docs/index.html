LIVE BOARDS

Real-time departures at your station.

Instantly monitor live platforms, delay minutes, and vehicle locations from the official EFA-BW transit backend without opening browser tabs or navigating heavy portals.

Live delay tracking

Distinguishes scheduled timetable slots from real-time GPS feeds. See live delays like +4' or +7' and on-time confirmations.

vvs departures Schlossplatz

City transit first

Defaults to regional lines: U-Bahn, S-Bahn, buses, Rack Railway (Zacke), and Cable Car. Use --all to include long-distance ICE/IC trains.

vvs departures --all

Platforms & bus bays

Shows exact train platforms (Gleis 1–16) and street-level bus/light-rail bays (e.g. Pos. 1, Pos. 5) at busy interchanges.

platform and position info

Flexible limits

Quick glimpse or full monitor board: adjust result count on demand with --limit N (defaults to 10 rows).

vvs departures --limit 5

ROUTE PLANNER

Door-to-door trips with natural time.

Plan connections effortlessly with flexible German and English time syntax. Store your home stop once and query routes home or to appointments in seconds.

Natural time syntax

Write times inline: um morgen 8:00, friday, 17:30, 2026-10-01 08:00, or 1.10.

OFFLINE INDEX & UNIX PIPES

10,000+ stops offline. Ready for unix pipes.

Every station in the VVS network is indexed locally into the binary. Fuzzy station lookup takes milliseconds offline, with zero network lag.

Fuzzy & umlaut-safe

Typing feuerb, charlottenpl, or vaih resolves instantly. Umlauts (ä, ö, ü) and German ß normalize automatically.

vvs search feuerb

Official EFA IDs

Pass official regional stop IDs like 5006022 or de:08111:6022 directly when writing deterministic automation scripts.

vvs departures de:08111:6022

Clean JSON piping

Pass --json to pipe real-time transit data directly into Waybar, Polybar, Raycast, Neovim, or custom shell automation scripts.

vvs departures --json | jq .

INSTALL

Single static Go binary.

Install directly with Go in one command, or compile from source. The embedded station index and EFA API client require zero external dependencies, zero API keys, and zero background services.

Config file: ~/.config/vvs.json
Saves your home station so bare commands like vvs departures or vvs to Feuerbach know your base.
Terminal Install via go install
$ go install github.com/parnoldx/vvs@latest

  1. Install the binary. Run go install github.com/parnoldx/vvs@latest to place vvs on your $PATH.
  2. Set your home station. Run vvs home Schlossplatz (or let the wizard prompt you on your first run).
  3. Check transit instantly. Run vvs departures or vvs to Feuerbach anytime from any shell.
Windows: the one-liner above needs a Unix shell. Download vvs-windows-amd64.tar.gz from the releases page, unpack vvs.exe into a folder on your PATH, and run it from PowerShell or any terminal.
FAQ

Frequently asked questions.

Do I need an API key or account to use vvs?

No! vvs queries the public EFA-BW timetable endpoint directly. No API token, registration, or credentials are required.

Which regions and transit networks are supported?

The entire Verkehrs- und Tarifverbund Stuttgart (VVS) coverage area: Stuttgart city (SSB), Esslingen, Böblingen, Ludwigsburg, Rems-Murr-Kreis, and Göppingen. That includes all U-Bahn, S-Bahn, buses, regional trains, the Zahnradbahn (Zacke), and the historic Seilbahn.

How does offline station search work without network calls?

vvs embeds a compressed index of over 10,000 official regional stops generated by tools/mkstations.py from the official VVS Haltestellen registry. Name matching, fuzzy scoring, and umlaut normalization run entirely on your CPU in milliseconds.

Can I pipe output into status bars like Waybar or Polybar?

Yes! Every command supports --json. You can easily write a 3-line shell script or Waybar module that reads upcoming departures for your station and shows live delay indicators on your desktop bar.
