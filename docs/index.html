Superpowers

        
Everything you need. Compiled into pure Go.

        
Departures boards, door-to-door trips, offline fuzzy search, and clean JSON piping — directly from your shell.

      


      

        

          

            01
            
Live Regional Boards

            
Real-time delays (+4'), train platforms (Gleis 1–16), and bus bays across U-Bahn, S-Bahn, buses, Zacke, and Seilbahn.

            
$ vvs departures

          

        


        

          

            02
            
Door-to-Door Trips

            
Write natural times: um morgen 8:00, friday 17:30, or --arrive. Save your home stop once in ~/.config/vvs.json.

            
$ vvs to Feuerbach

          

        


        

          

            03
            
Offline Stop Resolver

            
10,000+ official stops embedded locally. Fuzzy search, umlaut normalization (ä, ö, ü, ß), and EFA IDs resolve in 2ms on CPU.

            
$ vvs search feuerb

          

        


        

          

            04
            
UNIX Piping

            
Pass --json to pipe live transit data directly into Waybar, Polybar, Raycast, Neovim, or shell scripts.

            
$ vvs dep --json | jq .

Command reference

        
Clean UNIX commands & flags.

        
Single-word shortcuts, interactive pickers, and flags designed for terminal speed.

      


      

        

          
vvs departures [station]Live board for any station or home

          
vvs to <station>Trip connections from home to destination

          
vvs from <station>Trip connections from station back home

          
vvs <from> to <to>Connections between two custom stations

          
vvs search <term>List matching stations with EFA IDs

          
vvs toInteractive station & time picker wizard

          
vvs home [station]Show or set default home station

        


        

          
--at WHENDate/time: "8:00", "morgen 7:45", "friday", "1.10."

          
--arriveCalculate trips to arrive by target time

          
--allInclude ICE/IC non-local trains on boards

          
--limit NMax departures to display (default 10)

          
--jsonMachine-readable JSON output for status bars

          
↑ / ↓   TabNavigate picker & switch between stop/time

          
Enter · EscConfirm query or exit wizard

            Do I need an API key or account?
            
No! vvs queries the public EFA-BW timetable endpoint directly. No API tokens, registration, or credentials are required.

          

          

            Which regions are supported?
            
The entire VVS region: Stuttgart city (SSB), Esslingen, Böblingen, Ludwigsburg, Rems-Murr-Kreis, and Göppingen. Includes U-Bahn, S-Bahn, buses, regional trains, Zacke, and Seilbahn.

          

          

            How does offline search work?
            
vvs embeds a compressed index of 10,000+ regional stops. Name matching, fuzzy scoring, and umlaut normalization run entirely on your CPU in milliseconds.

          

          

            Can I pipe into status bars?
            
Yes! Every command supports --json. You can easily write a 3-line Waybar or Polybar module that shows live delay indicators on your desktop bar.
